# Shorts Maker

Free YouTube video processing app built with Streamlit.

## Features

- YouTube video download
- YouTube transcript extraction
- Automatic captions
- 9:16 vertical video conversion
- Caption burning
- Free text-to-speech
- Final video download

## How to use

1. Paste a YouTube URL.
2. Select the desired settings.
3. Click **Process Video**.
4. Wait for processing to finish.
5. Download the final video.

## Requirements

The app uses:

- Streamlit
- yt-dlp
- YouTube Transcript API
- Edge TTS
- FFmpeg

## Note

This project does not use Gemini API.
